# Instagram 내보내기 시험 데이터

사용자가 이 비공개 저장소에 업로드하도록 요청한 실제 내보내기 자료입니다.

- `instagram-080.014-2026-11-04-bV80AR5s.zip`: 전달받은 ZIP 원본. 변경하지 않습니다.
- `pinmap-items.json`: ZIP의 저장 게시물만 백엔드 입력으로 변환한 파일입니다. 작성자 캡션과 명시된 제목을 사용하며 컬렉션 분류·저장 이유를 AI 입력에 넣지 않습니다.
- `manifest.json`: 원본 SHA-256, 항목 수, 변환 방법과 한계입니다.

원본은 게시물 349건, 컬렉션 11개이며 사진·영상 파일을 포함하지 않습니다. 이 데이터로는 기본 목록 조회와 캡션 요약을 시험할 수 있습니다. 이미지·영상 분석은 해당 게시물에 원본 미디어를 추가해야 합니다. 다른 로컬 실행에서 수집한 화면 캡처는 이 저장소에 포함하지 않습니다.

다시 변환하려면 저장소 루트에서 `npm run prepare:data`를 실행합니다. 재변환에만 Python 3가 필요하며, 서버 실행에는 필요하지 않습니다. 변환 도구는 네트워크나 AI를 호출하지 않습니다.

실제 사용자 자료가 포함돼 있으므로 저장소를 공개하거나 외부에 재배포하기 전에 별도 검토가 필요합니다.
